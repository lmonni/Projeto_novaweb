# FrameYou

## Descrição do Projeto

A FrameYou é uma loja virtual de roupas.

## Objetivos

- Desenvolver uma loja virtual de roupas.
- Criar uma interface organizada e intuitiva.
- Utilizar HTML semântico na estrutura das páginas.

## Escopo

O projeto será composto por três páginas:

- Home
- Produtos
- Contato

## EAP e Cronograma

| EAP | Atividade | Descrição |
|---|---|---|
| **1. Documentação** | 1.1 Levantamento de requisitos | Identificar e organizar os requisitos do projeto |
| **1. Documentação** | 1.2 Elaboração dos casos de uso | Definir os casos de uso do sistema |
| **1. Documentação** | 1.3 Criação da documentação técnica | Elaborar a documentação técnica do projeto |
| **1. Documentação** | 1.4 Preparação do manual do usuário | Preparar orientações para utilização do sistema |
| **2. Front-End** | 2.1 Desenvolver a tela inicial | Criar a página inicial da loja virtual |
| **2. Front-End** | 2.2 Criar a página de produtos | Desenvolver a página para apresentação dos produtos |
| **2. Front-End** | 2.3 Implementar o carrinho de compras | Desenvolver a funcionalidade do carrinho |
| **2. Front-End** | 2.4 Desenvolver a tela de login e cadastro | Criar as telas de acesso e cadastro dos usuários |
| **3. Banco de Dados** | 3.1 Modelar o banco de dados | Definir a estrutura do banco de dados |

| **3. Banco de Dados** | 3.4 Realizar testes de consultas e integridade | Testar consultas e verificar a integridade dos dados |
