# Nome do Projeto
# Projeto_novaweb

## Descrição do Projeto
O objetivo do Projeto_novaweb é desenvolver uma aplicação de software de forma organizada, com boas práticas de gerenciamento de projetos, controle de versão com Git e GitHub, buscando aplicar a organização no planejamento, documentação, desenvolvimento e versionamento durante a criação de uma loja virtual.

## Estrutura Analítica do Projeto (Resumo das entregas)
### 1. Documentação
- Levantamento de requisitos
- Elaboração dos casos de uso
- Criação da documentação técnica
- Preparação do manual do usuário

### 2. Front-End
- Desenvolver a tela inicial
- Criar a página de produtos
- Implementar o carrinho de compras
- Desenvolver a tela de login e cadastro

### 3. Banco de Dados
- Modelar o banco de dados
- Criar as tabelas e relacionamentos
- Inserir dados iniciais (seed)
- Realizar testes de consultas e integridade
